# Privacy Policy for TimeFly

**Last updated**: August 20, 2026

TimeFly is an open-source desktop application designed to run entirely locally on your Windows computer.

## 1. Zero Data Collection
TimeFly **does not collect, transmit, store on remote servers, or sell** any personal information, telemetry, or user analytics.

## 2. Local Storage
All tracked data (such as focus timers, canvas titles, drawing tablet hardware metadata, and drawing session history) is stored strictly locally on your machine in SQLite database format located at:
`%USERPROFILE%\.timefly\timefly.db`

## 3. Network Access
TimeFly does not require internet connectivity to function and performs zero background tracking or outgoing telemetry requests.

## 4. Contact
For any inquiries or security questions, please visit [https://github.com/chiraitori/timeflytracking/issues](https://github.com/chiraitori/timeflytracking/issues).
